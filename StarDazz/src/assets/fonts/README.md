# Inter

Self-hosted variable WOFF2 files, normal style, weights 400–700. The original
Google Fonts stylesheet used the same font family and weights. Keeping the
Unicode subsets lets the browser download only the scripts it needs. Latin is
preloaded from `index.html`; CSS uses `font-display: swap`.

Source stylesheet (downloaded 2026-10-31 using a current Chrome user agent):
https://fonts.googleapis.com/css2?family=Inter:wght@400..700&display=swap

The files are Google Fonts Inter v20, served from `https://fonts.gstatic.com/s/inter/v20/`.
Only the stylesheet URLs have been changed to relative local paths. Font files
are unmodified and distributed under the SIL Open Font License in `OFL.txt`.
License source: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt

Vite emits content-hashed filenames so updates safely invalidate cached files.
